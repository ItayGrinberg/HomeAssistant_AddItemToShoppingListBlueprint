# Home Assistant - Add Item to Shopping List Automation Blueprint
This automation blueprint adds an item to a shopping list of your choice. It enables you to select the triggers and conditions for adding the item. Upon adding the item, it can also notify the Companion App on your phone and let you enter the list via the notification.

- The [Home Assistant companion app](https://play.google.com/store/apps/details?id=io.homeassistant.companion.android) must be installed.

## Usage

Once installed:
1. Create an automation using the blueprint.
2. Pick a trigger of your choice.
3. You may define a condition if you wish.
4. Fill in the name of the item that will be added to the shopping list.
5. Select the shopping list to which you would like to add your item out of the available to-do lists on your Home Assistant.
6. You may select a mobile phone to be notified upon adding the item.
